# FotiaTags 称号插件开发计划

## 项目概述
开发一个支持跨服同步、多语言、GUI管理的Minecraft称号插件。

## 核心功能

### 1. 称号系统
- 每个称号包含两部分：prefix（前缀）和 suffix（后缀）
- 提供两个PlaceholderAPI变量：
  - `%fotiatags_prefix%` - 当前选择称号的前缀部分
  - `%fotiatags_suffix%` - 当前选择称号的后缀部分
- 支持MiniMessage格式（包括CraftEngine的`<image:xxx:xxx>`格式）
- 支持PAPI变量格式（prefix2/suffix2）

### 2. 数据存储
- 支持MySQL和SQLite数据库存储玩家称号数据
- 存储内容：
  - 玩家UUID
  - 拥有的称号列表（含过期时间）
  - 当前选择的称号
- 支持导入/导出YML格式的称号配置

### 3. 命令系统
- `/fotiatags give <玩家> <称号> [时长]` - 给予玩家称号（永久或限时）
- `/fotiatags remove <玩家> <称号>` - 移除玩家称号
- `/fotiatags set <玩家> <称号>` - 设置玩家当前称号
- `/fotiatags list [玩家]` - 查看称号列表
- `/fotiatags reload` - 重载配置
- `/fotiatags export` - 导出称号到YML
- `/fotiatags import` - 从YML导入称号
- `/fotiatags menu` - 打开称号选择菜单

### 4. GUI系统
- 称号选择菜单：玩家选择自己拥有的称号
- 菜单配置格式参考示例，支持：
  - Layout布局
  - 自定义图标（material, name, lore, item_model, tooltip等）
  - 点击动作（sound, close, command等）
  - 称号物品显示已选择/未选择状态

### 5. 配置文件结构
```
FotiaTags/
├── config.yml          # 主配置（数据库、默认设置等）
├── tags.yml            # 称号定义
├── menus/
│   └── tag-select.yml  # 称号选择菜单配置
└── lang/
    ├── zh_CN.yml       # 中文语言
    └── en_US.yml       # 英文语言
```

## 已确认需求

1. 数据库配置：支持MySQL和SQLite
2. 时长格式：支持 `1d`, `7d`, `30d`, `permanent` 等格式
3. 权限节点：需要权限节点控制
4. 默认称号：支持默认称号配置
5. 称号过期处理：过期后自动切换到默认称号
6. 跨服同步机制：使用数据库

## 技术栈
- Minecraft版本：1.20+（Paper/Spigot）
- 依赖：PlaceholderAPI（软依赖）
- 数据库：MySQL/SQLite
- GUI框架：自实现基于配置的GUI系统

### 模块4: 命令模块 (gg.fotia.tags.command)

```

└── menu                         权限: fotiatags.command.menu
```

**时长格式解析**:
- `permanent` / `perm` / `-1` - 永久
- `30s` - 30秒
- `30m` - 30分钟
- `1h` - 1小时
- `1d` - 1天
- `7d` - 7天
- `30d` - 30天

## 配置文件示例

### config.yml
```yaml
# FotiaTags 配置文件

# 数据库配置
database:
  # 类型: mysql 或 sqlite
  type: sqlite

  # MySQL配置（当type为mysql时生效）
  mysql:
    host: localhost
    port: 3306
    database: minecraft
    username: root
    password: password
    pool:
      maximum-pool-size: 10
      minimum-idle: 2
      connection-timeout: 30000

# 默认设置
settings:
  # 默认语言
  language: zh_CN
  # 默认称号（玩家没有选择称号时使用，设为空则不显示）
  default-tag: ""
  # 过期检查间隔（秒）
  expire-check-interval: 60

# 调试模式
debug: false
```
